# Agentic Coding

Materials and projects from the Virginia Tech CS Graduate Students' Agentic Coding meeting.

## Weekly meeting

We meet **every Wednesday at 5:30 PM in DDS132**.

## Presentation materials

Presentation materials are available in [Sage](https://sage3.cs.vt.edu/). Open the **VT Server**, then select the **Agentic Coding Board** to find the meeting presentations.

## Session materials

- [Session 1: Skills and reference cleanup](session1/)
- [Session 2: Local Transcript](session2/) — convert audio and video recordings into timestamped text.
- [Session 3: Agentic coding tools](session3/) — presentation materials and tool demonstrations; no code project.
- [Session 4: Four-Agent Workbench](session4/) — a desktop application that coordinates System Engineer, Software Engineer, Tester, and Marketing agents.

Each session directory contains its project materials and any setup or usage instructions.
